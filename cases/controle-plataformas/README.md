# Controle de Plataformas Elevatórias Móveis

Este repositório está **em planejamento**. Ainda não há aplicação, suíte de testes ou demonstração executável publicada. Ele não deve ser usado como evidência de implementação em entrevistas.

## Problema a resolver

Registrar a disponibilidade e o uso de plataformas elevatórias móveis, com histórico de inspeções, bloqueios e responsáveis. Antes de implementar, é preciso validar as regras de negócio, os papéis de acesso, os dados obrigatórios e os critérios de segurança operacional com pessoas do domínio.

## Critérios para iniciar a implementação

1. Definir o escopo mínimo e os estados do equipamento: disponível, reservado, em uso, em manutenção e bloqueado.
2. Documentar riscos e critérios de aceite para reserva concorrente, inspeção vencida, indisponibilidade e trilha de auditoria.
3. Criar dados sintéticos e testes para as transições e permissões antes de declarar qualquer funcionalidade pronta.
4. Publicar instruções de instalação, execução, testes e limitações junto com o primeiro incremento executável.

O [portfólio SDET](https://github.com/fmchiava/sdet-portfolio) reúne os projetos com evidências executáveis atuais.
